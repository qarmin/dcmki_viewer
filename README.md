# Dcmki viewer

Simple DICOM viewer for quickly previewing DICOM files. 

It is designed to be a lightweight and portable tool that allows you to quickly check the contents of DICOM files, including images and PDFs, as well as inspect DICOM tags, without the need to install costly software.
